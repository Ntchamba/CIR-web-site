# Connaissances de l'assistant

Seule source de vérité du conseiller, avec ses outils (catalogue, réalisations, coordonnées, commandes lus en
base). Chaque fichier `.md` (hors ce README) est ajouté aux consignes du conseiller.

Règle : seulement des faits présents dans le projet (cahier des charges, règles de l'application, coordonnées déjà
affichées sur le site). Une fiche vide vaut mieux qu'une fiche fausse. Le catalogue n'est jamais recopié ici.
