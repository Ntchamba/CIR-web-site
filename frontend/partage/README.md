# Code commun aux deux applications React

- `api/` : `client.js` (appels HTTP + JWT), `socket.js` (WebSocket)
- `ui/` : composants de base (Bouton, Champ, Modale, Chargement, EtatVide, MessageErreur)
- `styles/` : `jetons.css` (couleurs, polices, espacements), `base.css`
- `utils/` : `format.js` (FCFA, dates), `usePageMeta.js` (titres et balises Google)
