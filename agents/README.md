# Agents IA de l'application

Les prompts, connaissances et évaluations de l'assistant IA (API Gemini) sont dans **`backend/agents/`** : la racine du
service Railway du back-end est `backend/`, ce dossier doit en faire partie. Voir `backend/agents/README.md`.

Ne pas confondre avec `.claude/agents/`, qui décrit les agents Claude qui codent le projet.
