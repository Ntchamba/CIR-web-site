# Maquettes de référence (desktop et téléphone)

Reçues du propriétaire le 21 octobre 2026. Elles montrent la **structure et les pages** voulues
(accueil avec vidéo et sphère, catalogue, fiche produit avec panneau d'options, réalisations, connexion,
mes commandes). Pour les ouvrir, il faut y remettre le dossier `assets/img` d'origine.

**Les images de ces maquettes ne sont volontairement pas conservées ici et ne doivent pas être utilisées** :
le propriétaire a fourni d'autres images (`backend/medias_reference/images/`). Seule la vidéo des maquettes est
retenue (`backend/medias_reference/video/`). Les textes entre crochets (`[PRIX]`, `[Nom du chantier]`…) sont des
emplacements : ne jamais les remplacer par des valeurs inventées.

Direction de design donnée ensuite (voir `docs/decisions/11-entree-3d.md`) : le site doit donner l'impression
d'**entrer** dedans (profondeur 3D au défilement) ; le fond blanc des maquettes n'est pas retenu.
