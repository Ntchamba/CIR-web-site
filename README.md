# CIR : application web

Application web du **Complexe Industriel Révélation SARL (CIR)**, Douala (Cameroun) : vente de revêtements
de sol en résine époxy pour la maison, l'industrie et l'entreprise.

- `prototype-1` : premier prototype (référence).
- `prototype-2` : reconstruction à partir de zéro, module par module (cette branche).

Architecture : `docs/architecture.md`. Avancement : `docs/taches/`.
